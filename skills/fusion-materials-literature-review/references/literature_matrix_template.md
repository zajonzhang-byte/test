## Fusion Materials Detailed Matrix

| Field | What To Extract |
| --- | --- |
| Citation | Author, year, journal, DOI if available |
| Material system | Composition, phase, coating, composite architecture |
| Fabrication route | Rolling, SPS, HIP, additive manufacturing, CVD, coating method, heat treatment |
| Initial microstructure | Grain size, texture, dislocation density, precipitates, interfaces, porosity |
| Exposure type | Neutron, ion, plasma, mixed plasma-material interaction, high heat flux |
| Irradiation species and energy | n, H, D, T, He, Fe, W, etc.; energy in eV/keV/MeV |
| Dose or fluence | dpa, ions/m2, particles/m2, appm He/H if provided |
| Temperature | Exposure or irradiation temperature and measurement method if relevant |
| Mechanical or thermal loading | Heat flux, pulse duration, cycles, stress, creep/fatigue condition |
| Characterization | SEM, TEM, FIB, APT, XRD, TDS, NRA, ERDA, nanoindentation, permeation test |
| Main observations | Surface morphology, bubbles, voids, hardening, retention, cracking, phase changes |
| Proposed mechanism | Trap formation, bubble growth, segregation, transmutation, recrystallization, etc. |
| Fusion relevance | Divertor, first wall, blanket, tritium safety, DEMO relevance |
| Limitations | Ion vs neutron gap, low dose, short exposure, missing T, unrealistic temperature, small sample |
| Review use | Which paragraph, argument, figure, or table this paper supports |
