# Section Patterns

Use these patterns to draft or revise review sections.

## Chinese Paragraph Pattern

```text
[主题判断句] 在聚变堆[部件/服役环境]中，[材料/机制]的关键问题在于[核心矛盾]。
已有研究表明，[证据1]；同时，[证据2]。
然而，这些结果之间的差异可能与[温度/剂量/通量/制备工艺/表征尺度]有关，因此不能简单外推至[DEMO/第一壁/偏滤器/包层]条件。
从机制上看，[缺陷、氢氦俘获、气泡、偏析、相变、开裂等]可能是导致[性能变化]的主要原因。
因此，后续研究需要重点解决[具体可验证问题]。
```

## English Paragraph Pattern

```text
In fusion-relevant [component/environment], the central challenge for [material] is [technical tension].
Existing studies indicate that [evidence 1], while [evidence 2].
The apparent discrepancy is likely related to differences in [temperature/dose/flux/microstructure/testing method], which limits direct extrapolation to reactor conditions.
Mechanistically, [defect evolution, gas trapping, bubble growth, segregation, phase instability, cracking] provides a plausible explanation for [property change].
Future work should therefore focus on [specific measurable gap].
```

## Section Ending Pattern

```text
总体来看，[材料/机制]研究已从[早期关注点]逐步转向[当前关注点]。
但现有证据仍主要受限于[实验条件或表征限制]，特别是在[聚变相关变量]耦合作用下缺乏系统比较。
这意味着该方向的核心问题不是单一性能优化，而是如何在[辐照稳定性、氚安全、热机械可靠性、工程制造]之间建立可验证的设计准则。
```
