# Codex Skills Backup

This repository stores Codex skills for tungsten and fusion-materials research writing.

## Skills

- `skills/fusion-materials-literature-review`: literature review workflow for nuclear fusion materials.
- `skills/w-he-h-migration-writing`: specialized writing workflow for W-H-He, VASP, and CINEB research on hydrogen migration near interstitial helium clusters in tungsten.

To use on another device, copy a skill folder into your Codex skills directory, for example `~/.codex/skills/`.
